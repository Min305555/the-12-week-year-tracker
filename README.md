# THE 12-WEEK YEAR TRACKER

Giao diện web tĩnh để lập kế hoạch theo chu kỳ 12 tuần, theo dõi mục tiêu và checklist Kế hoạch/Thực tế.

## Chạy thử

Mở `index.html` trong trình duyệt. Việc nhập và xuất workbook Excel cần kết nối Internet để tải thư viện SheetJS. Dữ liệu ứng dụng lưu trong bộ nhớ trình duyệt trên thiết bị hiện tại.

## Trạng thái hiện tại

Đây là bản mẫu giao diện phía trình duyệt. Chưa có đăng nhập bảo mật, cơ sở dữ liệu dùng chung, đồng bộ tự động với workbook gốc hoặc cấu hình triển khai hoàn chỉnh trên Vercel.

Workbook nguồn chứa nội dung kế hoạch cá nhân và bị loại khỏi Git theo `.gitignore`. Bí mật, mật khẩu và biến môi trường không được commit.
